## 2. 프로젝트 소개

**하나 금융상품 맞춤 추천 서비스**는 사용자의 기본정보와 투자성향을 바탕으로 금융상품을 추천하고, AI 챗봇을 통해 금융상품에 대한 상담을 제공하는 웹 서비스입니다.

회원가입 과정에서 입력한 **나이, 성별, 투자성향, 직업, 소득** 등의 정보를 활용하여 금융상품을 분석하고 사용자에게 적합한 상품을 제공합니다.

또한 AI 금융상품 상담 챗봇을 통해 사용자가 직접 질문하면 금융상품 데이터를 기반으로 상품 추천 및 비교 정보를 제공합니다.

### 주요 목표

* 사용자 정보 기반 맞춤형 금융상품 추천
* 금융상품의 금리 및 가입조건 비교
* AI 챗봇을 활용한 금융상품 상담
* 회원별 맞춤형 서비스 제공
* 간단하고 직관적인 금융 서비스 UI 구현

## 4. 주요 기능

### 4.1 회원가입

사용자는 다음 정보를 입력하여 회원가입할 수 있습니다.

* 아이디
* 비밀번호
* 이름
* 이메일
* 나이
* 성별
* 투자성향
* 직업
* 연소득
* 프로필 사진

회원정보는 SQLite 데이터베이스에 저장됩니다.

### 4.2 로그인

아이디와 비밀번호를 이용하여 로그인할 수 있습니다.

로그인 성공 시 인증용 쿠키가 생성되고 메인 페이지로 이동합니다.

### 4.3 맞춤형 금융상품 추천

회원가입 시 입력한 정보를 기반으로 금융상품에 점수를 부여하고 적합도가 높은 상품을 추천합니다.

추천에 활용되는 정보는 다음과 같습니다.

* 나이
* 투자성향
* 직업
* 소득
* 기본금리
* 최고금리

추천 결과에는 금융회사, 상품명, 최고금리, 기본금리, 가입기간, 가입금액, 가입대상, 상세 URL 등이 표시됩니다.

### 4.4 AI 금융상품 상담 챗봇

OpenAI의 GPT-4o-mini를 활용하여 금융상품 상담 기능을 제공합니다.

사용자가 입력한 질문과 회원정보, 금융상품 데이터를 함께 활용하여 상품 관련 질문에 답변합니다.

예를 들어 다음과 같은 질문을 할 수 있습니다.

> 저에게 맞는 예금상품 3개를 추천해주세요.

> 금리가 높은 예금상품을 알려주세요.

> 가입금액이 부담되지 않는 상품을 알려주세요.

> 추천상품 3개의 차이점을 비교해주세요.

챗봇은 CSV에 저장된 금융상품 데이터를 기준으로 답변하도록 구성하여 존재하지 않는 상품이나 금리를 임의로 생성하지 않도록 설계했습니다.

## 7. 추천 알고리즘

금융상품 추천은 CSV 데이터를 Pandas로 불러온 후 사용자 정보와 상품 정보를 비교하여 점수를 계산하는 방식으로 구현했습니다.

### 점수 계산 기준

```text
사용자 정보
   │
   ├── 나이
   ├── 투자성향
   ├── 직업
   └── 소득
        │
        ▼
상품 데이터와 키워드 비교
        │
        ▼
각 상품별 점수 계산
        │
        ▼
금리 점수 추가
        │
        ▼
점수가 높은 상품 정렬
        │
        ▼
상위 3개 상품 추천
```

예를 들어,

* 시니어 사용자의 경우 시니어·실버·연금·노후 관련 상품
* 안정형 투자자의 경우 예금·적금·원금·안전 관련 상품
* 학생의 경우 청년·학생·대학생 관련 상품
* 직장인의 경우 급여·월급·급여이체 관련 상품

등의 조건에 따라 추가 점수를 부여합니다.

또한 상품의 **최고금리와 기본금리**를 점수에 반영하여 최종 추천 상품을 결정합니다.

## 8. 실행 방법

### 8.1 프로젝트 다운로드

GitHub에서 프로젝트를 다운로드한 후 프로젝트 폴더로 이동합니다.

```bash
git clone [Repository URL]
cd [프로젝트 폴더]
```

### 8.2 필요한 라이브러리 설치

```bash
pip install fastapi uvicorn pandas python-dotenv openai python-multipart jinja2
```

### 8.3 환경변수 설정

프로젝트의 최상위 폴더에 `.env` 파일을 생성합니다.

```env
OPENAI_API_KEY=여기에_OpenAI_API_Key_입력
SECRET_KEY=원하는_비밀키_입력
```

`OPENAI_API_KEY`가 없으면 웹사이트의 회원가입 및 상품추천 기능은 사용할 수 있지만 AI 챗봇 기능은 사용할 수 없습니다.

### 8.4 서버 실행

```bash
python main.py
```

정상적으로 실행되면 다음 주소에서 서비스를 이용할 수 있습니다.

```text
http://127.0.0.1:1439
```

또는

```text
http://localhost:1439
```

## 9. 환경변수 설정

API Key는 코드에 직접 입력하지 않고 `.env` 파일을 사용합니다.

```env
OPENAI_API_KEY=your_api_key
SECRET_KEY=your_secret_key
```

GitHub에 업로드할 때는 `.env` 파일이 공개되지 않도록 `.gitignore`에 추가하는 것을 권장합니다.

```gitignore
.env
users.db
static/profiles/
__pycache__/
*.pyc
```
